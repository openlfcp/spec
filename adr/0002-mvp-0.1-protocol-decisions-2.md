# ADR 0002: MVP 0.1 protocol decisions, second batch

- **Status:** accepted
- **Decided by:** project owner, 2026-10-05
- **Applied by:** SPEC-PATCH-03 (baseline `mvp-0.1-baseline.3`)

## Context

Implementing the Rust SDK against `mvp-0.1-baseline.2` (LFCP-040 to
LFCP-043) and reviewing the Working Draft found places where LFCP-WIRE-01
left behavior open, named no error code, or published vectors that a
standard library could not reproduce. Agents reported them under stable IDs
and did not choose answers. The project owner decided each one. This record
lists every decision and where it was applied.

The decisions G-EP1 to G-EP6 were not approved in this batch and are not
applied.

## Value changes

Only two decisions change a published vector value:

- **G-KP2**: the Key Package vectors publish the HPKE ephemeral input
  keying material `ikmE` and seal with `skE = DeriveKeyPair(ikmE)`
  (RFC 9180 §7.1.3). This changes KP0, KPI and KPC, the
  `KEY_PACKAGE_BATCH` and `KEY_PACKAGE_PUT` messages and
  `hpke_recipient_mismatch_KP0`: 30 values.
- **V2**: `descriptor_extra_field` now expects `MALFORMED_MESSAGE`, where it
  named no code before: 2 added values.

Every one is listed, with its decision, in
[`migrations/mvp-0.1-baseline.3/value-changes.json`](../migrations/mvp-0.1-baseline.3/value-changes.json).
`scripts/check-baseline-changes.mjs` fails on any other changed or removed
value relative to `mvp-0.1-baseline.2`.

## Rejections with no named code

These decisions say a record is rejected but name no error code, and none
was invented: G-CP2 (route version not increasing), DV2, G-CAP4 escalation,
DV4 revoking a grant that is not covered, and W5 (Snapshot Sequence 0).
Their vectors expect `valid: false` with no `error`.

## Consequences

- Implementations move from `mvp-0.1-baseline.2` to `mvp-0.1-baseline.3`
  deliberately. Key Package code must derive the ephemeral key from
  `ikmE` to reproduce KP0, KPI and KPC.
- Vector consumers can read signers, DEKs and the invitation grant from
  `inputs` instead of deriving them.
- Rust and TypeScript SDKs add the new negatives to their vector suites.
